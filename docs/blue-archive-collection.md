# Blue Archive collection wishlist

112 requested character/variant entries. Original request order is preserved in wishlist.json.

## Folder layout

- Originals/Blue Archive: existing source assets, preserved.
- Restored/Blue Archive: existing playback derivatives, preserved.
- Previews/Blue Archive: compact posters, named by stable catalogue ID.
- Catalogs/Blue Archive: wishlist and provenance records.

New media should use Character/Variant subfolders within Originals and Restored. Existing playback paths stay intact until a bookmark-aware migration exists.

## Preview and quality policy

Use a representative full-composition frame, preserve aspect ratio, and generate a compact 1024-pixel-wide poster. Only animate the selected preview. Keep native/source dimensions separate from upscale/output dimensions; never label an upscale native 4K. Record source URL, acquisition date, content hash and whether the asset is original game data, a capture, or fan-made. A requested costume does not establish that a lobby animation exists.
