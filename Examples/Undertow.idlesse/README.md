# Undertow

Original copper-and-magenta contour artwork with an eight-second procedural wave.
Open this package in Studio or choose it as a wallpaper. Ripple Strength controls
the distortion; zero stops the animation. No pointer or audio permissions are needed.

The artwork is generated by `scripts/make-undertow.py`: one 2048-square PNG, about
1.1 MB on disk, plus a small scene description. Motion is rendered live rather than
stored as a video. A slight overscan keeps the displaced texture edges offscreen.
It is SDR artwork, not a 4K video or a reproduction of an existing album cover.

The eight-second timeline matches the displacement effect's period. The renderer's
output at 0 and 8 seconds is identical. No duplicated end frame is needed in exports.
